# Atualizar para V19 pelo iPhone
1. Exporte o backup local do V18.
2. Descompacte o ZIP V19 no app Arquivos.
3. No repositório `opera-wms-v17`, escolha Add file → Upload files.
4. Substitua todos os arquivos com mesmo caminho, incluindo `index.html`, `manifest.webmanifest`, `sw.js` e ícones.
5. Se o iOS não mantiver a pasta `icons` ou não permitir substituir todos os arquivos, pare antes do commit; use modo computador ou computador autorizado.
6. Faça commit na branch `main`.
7. Abra a URL do Pages e confira V19. Teste Check 360, guarda, histórico e backup.

Não apague dados do site antes de confirmar o backup. Os dados são locais e não sincronizam entre aparelhos.
